1. 이 도구가 다른 점

대부분의 AI 학습 도구는 "잘했어요" 또는 "다시 해보세요"라고 평가합니다. The Annoying Friend는 다릅니다. 학생 옆에 깐깐한 친구가 앉아 있다고 상상해 보세요. 학생이 잘 못 쓰면 친구가 살짝 잘난 척하고, 학생이 잘 쓰면 친구가 약 올라합니다. 학생은 평가를 받는 것이 아니라 친구를 약 올리려고 글을 다듬게 됩니다.

🎮

게임 같은 동기

"친구를 약 올리는" 게임으로 글쓰기가 즐거워집니다.

📚

글쓰기 규칙 기반

한국 초등 국어과의 주장 글쓰기 규칙을 그대로 평가에 반영합니다.

🪞

메타인지 강화

학생이 직접 도움을 청하고, 다시 쓰기 결정도 학생이 합니다.

학생이 얻는 것

  • 한 편의 완성된 주장 글 (서론·본론·결론·제목 포함)
  • 친구의 반응을 보며 스스로 개선해 본 경험
  • 친구의 마지막 평가 — 어느 부분이 좋았고, 어디가 아쉬웠는지

교사·학부모가 얻는 것

  • 학생이 어떤 순서로 글을 다듬었는지 그 여정 전체를 확인 가능
  • 학생이 도움을 몇 번 청했고, 평가를 몇 번 받았는지에 대한 기록
  • 관리자 페이지에서 세션 단위로 글쓰기 흔적을 시각적으로 검토

2. 사용 흐름 한눈에 보기

  1. 입장 — 첫 화면에서 학생 이름(닉네임 가능), 학년, 글 주제를 입력합니다.
  2. 글쓰기 — 4단계(서론 → 본론 → 결론 → 제목)를 순서대로 작성합니다. 각 단계마다 친구에게 도움을 청하거나 평가를 받을 수 있습니다.
  3. 마무리 — 모든 단계를 끝내면 친구가 마지막 평가를 줍니다. 학생은 완성된 글과 친구의 평가를 함께 받습니다.
한 세션 소요 시간 학생 수준과 주제 깊이에 따라 다르지만 30~60분이 일반적입니다. 도중에 잠시 멈췄다가 같은 기기·같은 브라우저로 돌아오면 진행 중인 단계부터 이어 쓸 수 있습니다.

3. 4단계 글쓰기

학생은 글을 다음 네 단계로 나누어 차례차례 작성합니다.

📝 서론 주장 한 문장
→
📑 본론 근거 3~5문단
→
🏁 결론 요약·강조
→
🏷️ 제목 한 줄로
→
🎉 완료 친구 평가

각 단계에서 학생은 ① 글을 쓰고 ② 필요하면 친구에게 같이 고민해줘로 도움을 청하고 ③ 친구한테 보여주기로 평가를 받고 ④ 다음으로 버튼을 눌러 그 단계를 마무리합니다.

화면 위쪽 단계 표시줄을 누르면 이미 끝난 단계를 다시 살펴보거나 고쳐 쓸 수 있습니다. 아직 도달하지 않은 단계는 비활성 상태로 표시됩니다.

4. 학생이 누르는 4가지 버튼

학생이 화면에서 누를 수 있는 버튼은 단계마다 다음 네 가지로 통일됩니다. 자유로운 채팅창은 없습니다. 학생의 모든 상호작용은 이 네 버튼을 거치도록 의도적으로 설계됐습니다.

🤝 같이 고민해줘

도움 요청 — 학생이 직접 청함

막혔을 때 친구의 도움을 부르는 버튼입니다. 평가가 아니라 도움이라는 점이 핵심입니다.

제한 단계마다(본론은 문단마다) 2회까지 사용 가능
선택지 "💡 아이디어가 안 떠올라" / "✏️ 글의 짜임이 헷갈려" / "🤷 그냥 전부 봐줘"

🎯 친구한테 보여주기

평가 요청 — 친구가 자동 평가

"이 정도면 친구가 인정해줄까?" 싶을 때 누릅니다. 친구는 글쓰기 규칙에 따라 평가하고, 그 결과로 친구의 다음 반응(잘난 척 vs 약오름) 모드가 결정됩니다.

제한 무제한

👀 본론 문단별 보여주기

본론은 문단마다 따로 평가

본론이 여러 문단이라면 한 번에 전체를 평가받지 않고 문단마다 따로 친구의 반응을 들을 수 있습니다.

사용 위치 본론 단계 안에서만 표시됩니다.

➡️ 다음으로

현재 단계 확정 + 다음 단계로 진입

이 단계의 글을 더 손보지 않겠다는 의미입니다. 누른 순간 단계가 잠기고 다음 단계로 넘어갑니다.

본론에서는 최소 1문단 작성 시 누를 수 있고, 정석은 3문단입니다.

설계 의도 채팅창을 없애고 4개의 명확한 버튼만 둔 것은 학생이 "내가 지금 무엇을 하고 있는가"를 늘 의식하게 하기 위함입니다. 도움을 청하는 행위, 평가를 받는 행위, 확정하는 행위가 각각 또렷하게 구분되어 메타인지 학습 효과를 높입니다.

5. 친구의 두 가지 모습

친구는 학생을 라이벌로 봅니다. 학생이 잘 쓰면 약 올라하고, 못 쓰면 잘난 척합니다. 이 두 모습은 친구의 표정과 말투로 학생에게 그대로 전달됩니다.

잘난 척 모드
학생이 아직 미흡할 때
"에이~ 그것도 모르겠어? 천천히 같이 해보자."
약오름 모드
학생이 잘 썼을 때
"헐... 좋네. 근데 이건 어때? 인정 못 해 아직."

승부 게이지

친구 표정 아래 좁은 게이지가 표시됩니다. 학생이 잘 쓸수록 좌측(학생 영역)이 길어지고 우측(친구 영역)은 빨갛게 변합니다. 친구가 약 오른 정도를 한눈에 보여주는 시각 신호입니다.

학생 72 : 친구 28

아직 평가를 한 번도 받지 않은 시작 시점에는 50:50으로 표시됩니다. 평가가 일어날 때마다 새로 계산되며, 시간 흐름은 따로 표시되지 않고 현재 상태만 보입니다.

6. 본론은 3~5문단까지

본론 단계에 들어가면 기본 3개의 글쓰기 칸이 위에서 아래로 나란히 표시됩니다. 학생은 글의 분량에 따라 칸을 늘리거나 줄일 수 있습니다.

  • 문단 추가 — 마지막 칸 아래 + 버튼으로 5번째 문단까지 늘릴 수 있습니다.
  • 문단 삭제 — 각 칸 우측 상단 − 버튼으로 줄일 수 있습니다. 단, 본론은 최소 3개 칸이 유지됩니다.
  • 문단별 평가 — 각 문단마다 도움 요청·평가 요청 버튼이 따로 있어, 부분적으로 친구의 반응을 들을 수 있습니다.
본론을 짧게 끝낼 때 학생이 본론을 한두 문단만 쓰고 결론으로 넘어가면, 친구는 다음 평가에서 "본론이 너무 짧다"는 신호를 받아 한 번 더 짚어줍니다. 결론에 도달하지 못하게 막지는 않으며, 학생의 선택을 존중하면서도 친구는 깐깐하게 반응합니다.

7. 돌아가서 다시 쓰기

이미 확정한 단계를 다시 고쳐 쓸 수 있습니다. 화면 상단의 단계 표시줄에서 끝난 단계를 누르면 두 가지 중에서 선택하는 화면이 나옵니다.

  • 그냥 보기만 — 그 단계에 학생이 쓴 글을 펼쳐서 다시 읽기만 합니다. 수정 불가.
  • 다시 쓰기 — 확인 후 그 단계의 확정을 풀고 글쓰기 칸으로 되돌아갑니다.
학습 가치 돌아가서 다시 쓰는 활동은 학생의 메타인지(자기 글을 객관적으로 보는 능력)를 단단하게 합니다. 이 도구는 학생이 마음을 바꿔 돌아가는 행동을 실패가 아니라 성숙의 흔적으로 기록합니다. 교사 페이지에서 회귀 흔적을 따로 확인할 수 있습니다.

8. 학생 글의 안전한 보관

학생이 쓰는 글은 세 가지 단계로 점차 안전하게 보관됩니다.

1단계

잠시 임시 보관

학생이 글자를 입력하는 동안에는 학생 자신의 브라우저에만 잠시 머뭅니다. 다른 누구의 컴퓨터로도 보내지지 않고, 브라우저 탭을 닫으면 자동으로 사라집니다.

2단계

정식 기록

학생이 4가지 버튼(같이 고민 / 친구 설득 / 본론 보여주기 / 다음으로) 중 하나를 누른 순간에만 그 시점의 글이 정식 기록으로 보관됩니다. 단순한 키 입력만으로는 절대 기록되지 않습니다.

3단계

교사용 분석 사본

같은 시점에 교사·연구자가 나중에 살펴볼 수 있도록 사람이 읽을 수 있는 형식의 사본이 함께 보관됩니다. 학생 사용 환경과는 분리된 서버 영역에 저장됩니다.

왜 이렇게 나눠 두었나요? 학생이 글을 다듬는 모든 글자 입력을 다 기록해 두면 분석할 때 노이즈가 너무 많아 의미를 읽기 어렵습니다. 학생이 의식적으로 버튼을 누른 순간만 영구 기록함으로써, 학생의 학습 여정에서 진짜로 의미 있는 순간만 깨끗하게 남깁니다.

개인정보 측면

  • 학생 이름은 닉네임 사용을 권장합니다.
  • 현재 단계에서는 회원가입·로그인 절차 없이 즉시 사용 가능한 형태입니다. 정식 학교 도입 단계에서는 회원 인증 시스템을 추가할 예정입니다.
  • 학생이 쓴 글은 시스템 운영자(학교·연구진)만 관리자 페이지를 통해 열람할 수 있습니다.

9. 교사·관리자 페이지

교사 또는 연구자는 별도의 관리자 페이지에서 학생들의 글쓰기 여정 전체를 살펴볼 수 있습니다.

접속 방법

  1. 관리자 로그인 페이지에 접속
  2. 운영자에게 발급받은 비밀번호 입력
  3. 관리자 메인 화면에서 전체 학생 세션 목록 확인

관리자 페이지에서 볼 수 있는 것

  • 세션 목록 — 학생 이름, 주제, 진행 중인 단계, 마지막 갱신 시각
  • 세션 상세 / 글쓰기 여정 — 학생이 시간 순서대로 어떻게 글을 다듬었는지, 친구에게 몇 번 도움을 청했는지, 평가를 몇 번 받았는지 시각적으로 표시됩니다.
  • 변경 비교 — 학생이 친구의 피드백을 받은 뒤 글을 어떻게 고쳤는지 이전 / 이후를 색깔로 표시(추가된 부분은 초록, 지운 부분은 빨강).
  • 데이터 내보내기 — 한 세션 또는 전체 세션을 엑셀에서 열 수 있는 표 형식으로 받기.
현재 단계의 인증 관리자 페이지는 비밀번호로 보호되지만, 학생 페이지는 누구나 접속하면 새 세션을 시작할 수 있습니다. 정식 학교 배포 단계에서는 학생도 로그인이 필요한 형태로 확장될 예정입니다.

10. 자주 묻는 질문

학생이 글을 쓰다가 잠시 멈췄다 다시 와도 이어 쓸 수 있나요?
같은 기기, 같은 브라우저로 같은 세션 주소에 다시 접속하면 마지막으로 친구에게 보여주기 / 도움 청하기 / 다음으로를 누른 시점까지의 글이 그대로 복원됩니다. 그 사이에 추가로 친 키 입력은 브라우저 탭을 닫으면 사라지므로, 중요한 변경 후에는 액션 버튼 중 하나를 눌러 두는 것을 권장합니다.
학생이 자유롭게 친구와 대화할 수 있는 채팅창은 왜 없나요?
의도적으로 제거했습니다. 학생이 글에 집중하지 않고 친구와 잡담만 나누는 행동을 막고, 학생의 모든 상호작용이 도움 요청 / 평가 요청 / 단계 확정 중 하나로 또렷하게 구분되도록 했습니다. 이것은 메타인지 학습 효과를 높이는 핵심 설계 결정입니다.
친구가 학생에게 너무 깐깐하면 학생이 상처받지 않을까요?
친구는 잘난 척 모드에서는 깐깐하기보다 살짝 으스대며 친절하게 도와주는 어조를 사용합니다. 약오름 모드는 학생이 잘 썼을 때만 나오는 것이라 오히려 칭찬에 가깝습니다. 둘 다 친구로서의 친근함 + 반말이라는 공통 어조를 지킵니다. 학생이 좌절감을 느끼는 어조는 사용하지 않도록 응답 가이드가 명시되어 있습니다.
친구의 평가는 어떤 기준으로 이뤄지나요?
한국 초등 국어과의 주장 글쓰기 규칙(서론 / 본론 / 결론별 평가 항목)을 기준으로 다섯 가지 평가 요소(주장의 명확성, 근거의 적절성, 근거의 관련성, 표현의 적절성, 짜임의 완성도)와 단계별 세부 신호를 함께 봅니다. 학생에게는 점수나 규칙 번호로 말하지 않고, 자연스러운 또래의 말투로 전달됩니다.
본론을 꼭 3문단 이상 써야 하나요?
시스템적으로는 한 문단만 써도 다음 단계로 넘어갈 수 있도록 열어두었습니다. 다만 친구는 다음 평가에서 "본론이 너무 짧다"는 신호를 한 번 더 짚어줍니다. 학생의 선택을 막지는 않지만, 글쓰기 규칙에 따른 깐깐한 반응은 유지됩니다.
학생이 쓴 글이 어디에 보관되며 누가 볼 수 있나요?
학생이 4가지 액션 버튼 중 하나를 누른 순간의 글만 시스템 서버에 기록됩니다. 그 외의 키 입력은 학생 본인의 브라우저에만 잠시 머무르고 탭을 닫으면 사라집니다. 기록된 글은 시스템 운영자(학교·연구진)가 관리자 페이지를 통해서만 열람할 수 있습니다.
학생 한 명이 글 한 편을 쓰는 데 얼마나 걸리나요?
학년·주제·학생 수준에 따라 다르지만 일반적으로 30~60분입니다. 한 차시 수업 안에서 마무리할 수도 있고, 1~2일에 걸쳐 나누어 쓸 수도 있습니다(같은 기기에서 이어 쓰는 한).
여러 학생이 동시에 사용할 수 있나요?
가능합니다. 각 학생은 자기만의 세션을 가지며, 다른 학생의 글과는 분리되어 있습니다. 학교 단위 동시 접속 규모는 시스템 운영자에게 사전 안내된 사양 범위 내에서 보장됩니다.
